# Employee Onboarding Portal — ServiceNow

## Sobre o projeto

O Employee Onboarding Portal é um projeto desenvolvido na plataforma ServiceNow com o objetivo de organizar e automatizar o processo de integração de novos colaboradores em uma empresa.

A solução utiliza o Flow Designer para gerenciar solicitações, encaminhar aprovações ao gestor e executar ações de acordo com a decisão tomada.

## Problema de negócio

O processo de integração de novos colaboradores envolve diferentes etapas, como registrar informações, obter aprovação do gestor e preparar os equipamentos necessários.

A proposta deste projeto é organizar essas etapas e reduzir atividades manuais por meio da automação de processos.

## Funcionalidades

- Formulário para solicitação de onboarding.
- Fluxo de aprovação pelo gestor.
- Criação automática de tarefa após a aprovação.
- Tratamento de solicitações rejeitadas.
- Atualização do status da solicitação.
- Registro de comentário sobre a rejeição.

## Tecnologias utilizadas

- ServiceNow App Engine Studio
- ServiceNow Flow Designer
- Tabelas e registros da plataforma ServiceNow
- Fluxos de aprovação e lógica condicional

## Como funciona

1. Uma solicitação de integração de novo colaborador é registrada.
2. A solicitação é encaminhada ao gestor para aprovação.
3. Se aprovada, o fluxo cria uma tarefa para preparar o onboarding.
4. Se rejeitada, o fluxo atualiza o status da solicitação e registra um comentário sobre a rejeição.

## Objetivo de aprendizado

Este projeto foi desenvolvido para praticar a criação de aplicações e a automação de processos na plataforma ServiceNow, utilizando aprovações, condições, atualização de registros e criação de tarefas.
